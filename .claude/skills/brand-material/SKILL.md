# Brand Material Skill

Create professional marketing materials that are visually derived from the existing website in the current project.

The website is the primary source of truth for the brand.

## Core principle

Do not create generic marketing designs.

Do not make something that merely "looks nice".

The finished material must feel like it belongs to the exact same company, brand, website, and design system.

A customer should be able to see the website and the marketing material next to each other and immediately recognize that they belong together.

The result must feel intentionally art-directed by a professional designer, not generated by AI.

## First: inspect the existing project

Before creating anything:

1. Inspect the complete website implementation.
2. Identify:
   - Brand colors
   - Typography
   - Font hierarchy
   - Logo usage
   - Spacing system
   - Border radius
   - Shadows
   - Background treatments
   - Image style
   - Icon style
   - Button style
   - Layout principles
   - Visual motifs
   - Animation style
   - Tone of voice
   - Key selling points
   - Calls to action
3. Inspect existing assets:
   - Logos
   - Images
   - SVGs
   - Icons
   - Fonts
   - Backgrounds
   - Illustrations
4. Read relevant content and copy from the website.
5. Identify what makes the website visually distinctive.

Do not invent a new brand identity unless explicitly requested.

## Website as design system

Extract a compact internal design system before designing.

Think in terms of:

- Primary color
- Secondary color
- Accent color
- Neutral palette
- Display typography
- Body typography
- Heading hierarchy
- Button treatment
- Card treatment
- Grid
- Spacing
- Image treatment
- Decorative elements
- Brand personality
- Copy style

Reuse these principles rather than blindly copying individual website elements.

The material should be adapted for its physical or advertising context.

## Match the medium

Adapt the design to the requested material.

### Business card

Prioritize:

- Immediate brand recognition
- Name
- Company
- Role
- Phone
- Email
- Website
- QR code if useful
- Clean information hierarchy

Avoid overcrowding.

### Flyer

Prioritize:

- Strong first impression
- One clear message
- Strong headline
- Short benefit-driven copy
- Relevant services
- Clear CTA
- Phone / WhatsApp / website
- QR code where useful

Do not turn the flyer into a miniature website.

### Brochure

Prioritize:

- Clear information hierarchy
- Logical reading flow
- Section structure
- Strong visual rhythm
- Appropriate information density

### Poster

Prioritize:

- Readability from distance
- One dominant message
- Strong typography
- Minimal information
- Clear CTA

### Social media advertisement

Prioritize:

- Immediate recognition
- Strong visual hook
- Short copy
- Mobile readability
- CTA

## Anti-AI-Slop rules

Always combine this skill with the project's anti-AI-slop principles.

The result must not look AI-generated.

Avoid:

- Random gradients
- Excessive glassmorphism
- Generic 3D blobs
- Floating abstract shapes
- Fake futuristic UI
- Random glowing elements
- Excessive rounded cards
- Unnecessary icons
- Generic stock-photo compositions
- Overly perfect symmetry
- Excessive decorative elements
- Random typography combinations
- "Modern startup" clichés
- Fake depth
- Generic AI-generated illustrations
- Visual noise
- Too many effects
- Unnecessary text
- Marketing buzzword overload

Do not add design elements simply because they make the design look more impressive.

Every visual element must have a reason.

## Premium design principle

Premium does not mean "more effects".

Premium means:

- Strong hierarchy
- Excellent typography
- Intentional whitespace
- Controlled contrast
- Strong composition
- Appropriate image selection
- Precise spacing
- Clear communication
- Consistency with the brand
- Restraint

When in doubt, simplify.

## Existing website > generic trends

Never force current design trends onto the brand.

If the website is minimal, the material should be minimal.

If the website is bold, the material can be bold.

If the website uses dark cinematic visuals, translate that visual language into print appropriately.

If the website is traditional and trustworthy, do not suddenly create a futuristic startup design.

## Content rules

Use real information from the existing website whenever possible.

Do not invent:

- Phone numbers
- Addresses
- Email addresses
- Prices
- Certifications
- Reviews
- Customer numbers
- Claims
- Services
- Company history

If important information is missing, use a sensible placeholder and clearly identify it.

Never fabricate credibility.

Keep copy concise.

Marketing material is not a website dump.

## QR codes

When a QR code is requested:

- Generate a real QR code.
- Use the actual URL or contact destination.
- Ensure sufficient contrast.
- Leave sufficient quiet zone around it.
- Never fake a QR code visually.
- Test that the generated QR code contains the intended destination.

For WhatsApp:

Use the real WhatsApp number.

If a predefined message is appropriate, encode the message into the WhatsApp URL.

Example:

https://wa.me/NUMBER?text=ENCODED_MESSAGE

Only use information actually available in the project.

## Print quality

When creating print material, think like a professional print designer.

Use:

- Correct dimensions
- Correct orientation
- Appropriate bleed
- Safe margins
- High-resolution assets
- Vector graphics where possible
- CMYK considerations where applicable
- Embedded or properly referenced fonts
- Print-safe contrast
- Correct PDF export settings

Never create a fake "photo of a flyer".

The output must be the actual artwork.

If the user asks for a print-ready PDF, produce a proper print-ready PDF.

If the user asks for front and back separately, create two separate artwork files.

## Layout

Start with composition, not decoration.

Before implementation, determine:

1. Main visual focus
2. Primary message
3. Supporting information
4. CTA
5. Brand anchor
6. Contact information

Use a deliberate grid.

Do not center everything by default.

Use asymmetry when it improves the composition.

Use whitespace intentionally.

## Images

Prefer existing brand imagery from the website.

If suitable images do not exist:

- Use image generation only when appropriate.
- Match the visual language of the existing website.
- Avoid obvious AI imagery.
- Avoid overly polished stock-photo aesthetics.
- Avoid strange hands, faces, objects, text, or impossible scenes.
- Prefer realistic, believable imagery.

If the brand does not need imagery, do not add imagery.

## Relationship between website and material

The material should not be a screenshot of the website.

Instead:

Website:
digital experience

Marketing material:
physical/advertising translation of the same brand

Reuse:

- Color language
- Typography
- Visual motifs
- Photography style
- Tone
- Brand personality
- Key messaging

But redesign the composition for the medium.

## Existing components

If the project already contains reusable visual components, inspect them before creating new ones.

Reuse:

- Logo
- Icons
- Buttons
- Typography
- Design tokens
- CSS variables
- SVGs
- Image assets
- Brand patterns

Do not duplicate assets unnecessarily.

## 21st.dev

If the project has access to the 21st.dev MCP and a UI component could meaningfully help with the design system or supporting digital material:

Use it selectively.

Do not use components simply because they exist.

The final material must still feel like one coherent brand.

## Workflow

### Phase 1: Brand audit

Inspect the website and project.

Determine the visual language.

### Phase 2: Material strategy

Determine what information and visual hierarchy make sense for the requested format.

### Phase 3: Art direction

Create a clear composition based on the existing brand.

### Phase 4: Implementation

Build the actual artwork using appropriate tools and assets.

### Phase 5: Quality control

Check:

- Does it clearly belong to the website?
- Does it look professionally designed?
- Does it look human-designed rather than AI-generated?
- Is the hierarchy immediately understandable?
- Is the CTA obvious?
- Is all information correct?
- Are spacing and alignment precise?
- Are images appropriate?
- Is the logo used correctly?
- Is the material appropriate for its physical size?
- Is it actually print-ready if print was requested?

### Phase 6: Refinement

Remove anything unnecessary.

The final design should usually contain less than the first draft.

## Important

Do not ask unnecessary questions if the website already contains the required information.

Use the project as the source of truth.

If the user says:

"Mach mir einen Flyer für diese Website"

automatically inspect the website, derive the brand system, select appropriate content, and create the flyer.

If the user says:

"Mach mir Visitenkarten dazu"

automatically translate the same identity into a business card.

If the user says:

"Mach eine Broschüre"

automatically adapt the same identity into a brochure.

Always preserve brand consistency.

The goal is not to make a beautiful standalone design.

The goal is to make a professional piece of marketing material that looks like it was created as part of the same brand system as the existing website.
